# Little Luck — Research workspace

The budget-tracking interface has been removed at the user's request. Existing browser-local records remain exportable and have not been erased. No real-lottery analysis or prediction engine is implemented.

A synthetic probability sandbox is proposed but has not been built. The site currently displays its scope and a previous-records export control.

Run `npm start` for local preview, `npm run build` for static assets and `npm test` for retained legacy record validation. Those tests do not validate any prediction functionality. GitHub Actions builds and deploys only dist/.
