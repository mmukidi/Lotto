Does a pattern survive new data?

Simulated independent draws: five values from a fictional pool of 20. Methods learn from 400 training draws, then face the same 2,000 separate test draws. Real historical data is never used in this experiment.

Intervals are approximate 95% confidence intervals for each simulated mean, not predictions or proof that one method is better. All methods have an expected 1.25 matches under the uniform independent model. A single run can vary by chance.
